# FST visual production manifest

Production date: 28 July 2026
Mode: `photorealistic-natural` with one deterministic social composition
Creative board: `4c0f59ef-38c4-451c-953b-4f5460d8bd7f`

## Art direction

Original Malta- and Europe-oriented documentary business photography. The shared
visual language uses pale limestone, navy and cobalt with restrained terracotta,
natural Mediterranean daylight, believable professional environments and varied
working compositions. The set intentionally excludes KMFINCO's inherited
seated-boardroom visual treatment. No generated image contains a logo, watermark
or readable document text.

## Provenance and export notes

- Eleven photographic sources were generated specifically for FST with the
  built-in image generator and visually inspected before placement.
- Working PNG sources are kept locally under ignored `tmp/imagegen/`; the
  production WebP and JPEG exports are tracked in the repository.
- Web exports use attention-aware cover resizing and WebP quality 86.
- `public/og.jpg` is reproducibly generated by `scripts/generate-og.mjs`; the
  approved vector logo and visible text are composed deterministically.
- All deployed image references are checked against the KMFINCO source asset
  fingerprints by the brand-separation test.
